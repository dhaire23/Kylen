# Media folder

Drop files here using the exact names listed in `config/media.config.js` — the site picks them up automatically.

| Folder | What goes here |
|---|---|
| `hero/` | Opening-sequence clips: `hero-01-desktop.mp4`, `hero-01-mobile.mp4`, `hero-01-poster.jpg` (and 02, 03…) |
| `training/` | Secondary training loop: `training-01.mp4` (+ `-poster.jpg`) |
| `details/` | Cinematic detail loops: `detail-01.mp4`, `detail-02.mp4`, `detail-02-mobile.mp4` |
| `founder/` | `delone-portrait.jpg`, `chapter-01-the-field.jpg` … `chapter-04-the-coach.jpg` · contains the authentic `delone-dumbbell-row` photo |
| `interview/` | `founder-film.mp4` + `founder-film-poster.jpg` (or use a YouTube/Vimeo link in the config) |
| `editorial/` | `coaching-in-person.jpg`, `coaching-online.jpg`, `coaching-consult.jpg`, `find-your-grit.jpg`, `apply.jpg` |
| `clients/` | `client-training-01.mp4` (client consent required) |
| `transformations/` | `client-01-before.jpg` + `client-01-after.jpg`, … (written consent required) |
| `closing/` | `closing-desktop.mp4`, `closing-mobile.mp4`, `closing-poster.jpg` |
| `products/` | Covers for digital products (1200×1500) |
| `og/` | `big-grit-og.jpg` — social share image (1200×630) |

Full specs and the compression script: `docs/MEDIA-GUIDE.md`.
